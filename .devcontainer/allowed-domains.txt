# Package registries
# registry.npmjs.org is Cloudflare anycast (a 104.16.0.0/12 pool) and hands
# back a different subset per query, so no snapshot of A records is complete —
# init-firewall.sh resolves it DNS_ROUNDS times to widen the capture, but a
# runtime `npm install` can still hit an unpinned edge. This is why the MCP
# servers are installed once in post-create.sh (before the firewall comes up)
# and launched from disk rather than via `npx -y`, which would put a registry
# fetch on every MCP server start.
registry.npmjs.org
pypi.org
files.pythonhosted.org

# GitHub (clone/push, gh CLI, GitHub MCP server, nflverse release downloads)
#
# The authoritative list is fetched live from https://api.github.com/meta by
# init-firewall.sh at startup — do NOT rely on the entries below alone.

# "classic" blocks share a stable prefix; the other twenty are Azure regional
