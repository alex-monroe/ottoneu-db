# Week of November 17–23, 2026

A steadier live score worm and an earlier power-rankings ballot for the hosts, plus the site's database moving to its own server.

## New features

### Power rankings
- **Open next week's ballot early.** Hosts recording on Monday night can now open the following week's ballot and reveal at /podcast/power-rankings (for example `?week=11`) instead of waiting for the Tuesday rollover. The default week and the listener pages (/power-rankings and /power-rankings/vote) are unchanged. (#830)

## Fixes
- **Live worm no longer jumps at kickoff.** When a slate of games kicked off, the win-probability history on the live score worm could shift by around 15% for a few minutes, then shift back. Starters in a game that had just started now count right away, so the graph stays put. (#838)

## Internal changes
- Live score updates and free-agent auction posts to Discord now run from our own server instead of GitHub's scheduler. Auction posts go out every five minutes, and failures are reported through Healthchecks.io rather than GitHub issues (#831, #832, #833).
- The site's database moved from hosted Supabase to a self-hosted copy on our own server on November 23. Nothing changes on the site. The move was planned, built and rehearsed over the week, and the old hosted project was retired afterwards (#835, #836, #837, #841).
- Database commands for developers and agents (`just sql`, `just migrate`, `just gen-types`, `just db-lint`) replace the old Supabase tools, and agent tooling and docs now point at the new database (#839, #840).
- The live loop now also publishes a league-agnostic NFL play-by-play feed to the shared database, so the sister app Roster Loom can score the same plays under its own league settings (#842).
